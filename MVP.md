# MVP · Web pública

## Resultado mínimo
Una persona entiende qué hace DesarrollAMO, ve evidencia/trabajos seleccionados, encuentra contacto y puede consultar políticas públicas desde una web mantenible.

## Flujo mínimo
1. Inicio explica propuesta.
2. Servicios concretos.
3. Trabajos/evidencia seleccionada.
4. CTA de contacto.
5. FAQ y políticas.
6. Footer oficial único.
7. Deploy sólo desde `public/`.

## Aceptación
- `npm run check` pasa;
- sin placeholders ni datos privados;
- links internos válidos;
- responsive y navegación por teclado básica;
- Branding/Design System fijados por versión;
- Netlify publica exclusivamente superficie pública.

## Fuera del MVP
- exponer arquitectura/operación interna;
- métricas/clientes ficticios.
